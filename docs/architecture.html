Capstone 项目架构：React SPA → Express API → MongoDB Atlas

图中每一个方块都对应仓库里的一个真实模块；括号内是文件路径。数字为实际条目数，非估算。

图例 ──▶ 请求（含 JWT） ◀── JSON 响应 客户端层 服务端层 数据层

① 客户端 · Browser

路由 App.jsx

/ · /projects · /projects/:id
/blog · /blog/:id · /contact
/login · /register

HTTP 客户端 api/client.js

axios 实例 + 请求拦截器自动附加

10 个页面 · 12 个可复用组件
受保护路由守卫 ProtectedRoute.jsx

──▶ HTTPS / JSON API（22 个路由：11 公开 · 11 需 JWT）

② 服务端 · Express (Node.js)

中间件链 app.js

helmet() cors(CLIENT_URL) express.json() morgan() protect() authorizeOwner(model,'author') notFound() → errorHandler()

protect()：校验 Authorization 头中的 JWT → 查库 → 挂载 req.user，失败返回 401； authorizeOwner()：文档作者 ≠ 当前用户时返回 403（仅 PUT/DELETE /api/blog/:id 使用）。

路由 routes/ 4 个文件

userRoutes.js → /api/users
projectRoutes.js → /api/projects
blogRoutes.js → /api/blog
messageRoutes.js → /api/contact

控制器 controllers/ 5 个文件

user · project · blog · comment · message

只负责业务逻辑与状态码；异步错误交给 express-async-handler 转交中央错误中间件。

模型 models/ 5 个文件

User · Project · BlogPost · Comment · Message

Mongoose schema 校验 + bcrypt 哈希钩子 + populate() 关联查询。

──▶ Mongoose ODM（MONGODB_URI，凭据仅存于 .env）

③ 数据层 · MongoDB Atlas

users projects blogposts comments messages

所有集合由 Mongoose 按 schema 写入，唯一索引保护 users.email 与 users.username（重复插入返回 400）。

④ 数据关系（ObjectId ref）

User ──1 : N──▶ Project

Project.user → User

列表与详情用 populate('user','username email')

User ──1 : N──▶ BlogPost

BlogPost.author → User

作者字段同时是 403 鉴权依据

BlogPost ──1 : N──▶ Comment

Comment.post → BlogPost

删除文章时级联删除其评论

User ──1 : N──▶ Comment

Comment.author → User

评论列表 populate('author','username')

Message（独立集合）

POST /api/contact → Message

访客留言无需账号，因此不建关联

⑤ 两条代表性请求路径

A. 公开读取：博客详情

GET /api/blog/:id

  1. BlogDetail 页面在 useEffect 中发起请求
  2. axios baseURL 取 VITE_API_URL，无 token 也能访问
  3. cors 放行 → blogRoutes → getPostById
  4. BlogPost.findById().populate('author') + 查询该文章的全部 Comment
  5. 返回 200 {success,data:{…,author,comments}}，页面渲染作者与评论

B. 受保护写入：删除他人文章

DELETE /api/blog/:id

  1. AdminDashboard → PostManager 调用 api.delete()
  2. 请求拦截器附加 Bearer <JWT>
  3. protect()：验签 + 查库，失败 → 401
  4. authorizeOwner()：post.author ≠ req.user._id → 403
  5. 作者本人：删除评论 + 删除文章 → 200；否则 errorHandler 输出统一错误 JSON

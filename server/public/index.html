Portfolio & Blog API

This is the deployed back end of the Full-Stack Portfolio & Blog capstone project: an Express + MongoDB REST API with JWT authentication. The React single page application consumes the endpoints below.

Health check: /api/health

Endpoint groups

  • /api/users — register, login, profile, current user
  • /api/projects — portfolio projects (public reads, protected writes)
  • /api/blog — blog posts (public reads, author-only updates) and comments
  • /api/contact — contact messages (public create, protected inbox)

See README.md in the submitted source archive for the full endpoint reference.
